# Reconstructed chat integration

Native contracts and static evidence are separated into `chat-client.md`,
`chat-input.md`, and `chat-server.md`. The connected REA checkpoint
`analysis/local/chat-rea-checkpoint.json` retains 24 Evidence records. Original
DLLs were analyzed read-only, never loaded into the reconstructed runtime.

## Implemented

- `src/cof/client/saytext.cpp` replaces the disposable SDK SayText source.
  BYTE + NUL string packets feed five 256-byte rows; oldest-message expiry,
  grouped continuation scrolling, console history and pager sound are retained.
  White pager text uses the original CHW metrics/TGA at x5, H/2+8+i*32.
  The original `cof_` map-name visibility condition is retained.
- `ui_font.cpp` adds the pager atlas, independently of existing credits text.
  `ui_draw.cpp` converts the pager's zero-alpha RGB coverage to RGBA, as for
  credits. The six original resolution assets are identical.
- `src/cof/server/chat.inc` supplies Host_Say: 128-byte formatted
  string including NUL, public/TEAM prefix, sender echo, relationship/mute
  filtering and one-second rate limit. The SDK SPEC-only branch is removed.
- `src/cof/vgui/ui.cpp` paints input with resource-selected EngineFont, its
  shadow and con_color, command literal, x8 and separate three-pixel gaps.
  It renders through source-owned UI bridge v3 without opening a dialog.
  `engine_chat.inc` handles command serialization; engine key_message still
  owns input, Enter/Escape and text editing. Input is limited to 120 bytes.
- Fresh configurations bind Y/U to public/team chat. A one-time asset-stage
  migration only fills unused keys when the command has no existing binding.

All integration is generated by `prepare_game.py` / `prepare_vgui.py`; vendor
trees are unchanged. Engine, UI, client and server are built with Waf.

## Explicit port differences and remaining integration

- UTF-8 editing, navigation/paste and a visible caret are host extensions;
  the native editor is ASCII and append-only. Cyrillic maps to the installed
  CP1251 pager atlas, unsupported Unicode to `?`. Broken final UTF-8 sequences
  are removed before submission, and transport truncation respects boundaries.
  Embedded double quotes become apostrophes; native only replaced semicolons.
- Wrapping measures through the host engine's console-font API. Original also
  used that API rather than pager metrics, but the host notification/measurement
  font is not yet the original EngineFont. Legacy `/(...)` width-skip tokens
  are not interpreted by the current wrapper.
- Native viewport menu IDs 2/3/5/6 have a conditional AllowedToPrintText gate.
  Those viewport states are not reconstructed here. The server computer/phone
  interaction flag +1ea0 is likewise documented but not connected to a fake
  death/freeze flag. These are remaining integration points, not completed
  gameplay recovery.
- Single-player key_message retains the host's simulation-pause behavior;
  multiplayer simulation continues. Notification placement above input uses
  the host notification rows. No native pause equivalence is claimed.

## Validation

`tools/smoke_chat.ps1` runs the own listen server and invokes engine
Con_CharEvent/Key_Message entrypoints, then checks real received SayText packets:
public text with Cyrillic/quotes/semicolon/backspace, team prefix, rate limit,
120-byte input / 128-byte packet bounds, Escape, whitespace rejection, five-row
overflow, malformed packet rejection, expiry and reset. The opt-in fixture
ignores physical SDL key/text events to isolate the shared desktop. This is not
a claim of testing physical Y/U keys or a second network client.

The temporary `cof_chat_fixture.bsp` copies SDK geometry with only its intro
trigger target disabled; it is removed afterward. The coop prefix exercises
the actual map gate. Config bytes are restored after each run. Captures and
module inventories accompany `analysis/local/chat-1280x720.json` and
`chat-1920x1080.json`. Input selected Verdana13 at 720p and Verdana20 at 1080p.
The earlier 720p run used the map's scripted fades; the later 1080p fixture
removes them for visual inspection. Both protocol runs passed.

The module audit confirms nine x86 modules from own builds/official SDL and
no original game binaries. Cross-client team/mute filtering still needs a
multi-client integration run when the coop game-rules reconstruction is ready.
